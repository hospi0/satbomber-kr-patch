## 디스크 파일(25개)
- `0KRNL.BIN` 786,432 B — SH-2 커널(첫 낱말 = 진입 주소 0x0600A114). **평문 SJIS = 저장 오류 문구뿐**(0xA90B0‥ «エラーばんごう·そうちがせつぞくされていません·…»), «ＳＴＡＧＥ　１‥５»(0xA8F34), 숫자표.

## 글자 출처(1차)
- 화면 낱말(ステージ·ポーズ·ボンバー·ボバる·けってい …)은 SJIS·EUC·UTF-16 어디에도 평문으로 없음.
- 스테이트 VDP1/VDP2 VRAM 32바이트 조각이 PROGRAM.BIN·0KRNL.BIN 에 거의 안 나옴(swap16 포함) → **그림·글자는 압축되어 있음**. HighRAM 도 거의 안 나옴(풀린 자료), LowRAM 은 98% 나옴(코드).
- ⏳압축 형식 판정: 스테이트 HighRAM 의 풀린 그림 ↔ PROGRAM.BIN 압축 덩어리 대응, 풀기 루틴 찾기(SH-2).
- ⏳메뉴 판(BOMBER STADIUM)의 면: s4 는 NBG0‥3 모두 켜짐(NBG0 256색 지도 그림, NBG2 폭탄 무늬, NBG1·NBG3 16색 = 렌더 도구가 검게 그림 — 판·버튼 글자일 가능성, 지도 주소 MPABN1 0x0404·MPABN3 0x1C1C 해석 확인 필요).
